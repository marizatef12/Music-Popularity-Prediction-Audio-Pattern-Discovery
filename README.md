# Music Analytics & Recommendation Platform

## Project Overview

An interactive music analytics and machine learning platform built with **Python, Machine Learning, and Streamlit**.

The project analyzes music data to understand song popularity, genre trends, artist similarity, and music characteristics, while providing interactive machine learning and recommendation features through a **5-page Streamlit application**.

## Key Features

* Song Popularity Prediction based on audio and music features
* Music Genre Classification and similar-song discovery
* Genre Trends Over Time to analyze how music genres evolve
* Artist Popularity and Similarity Analysis over time
* Customized Playlist Generator based on selected music features
* Interactive deployment using Streamlit

## Application Pages

### 1. Song Popularity Prediction

Predicts the popularity of a song based on its available music and audio features.

Users can enter the song characteristics and receive a predicted popularity score.

### 2. Genre Analysis and Similar Songs

Identifies the genre of a song and retrieves other songs belonging to the same genre.

This page allows users to explore songs within the identified genre.

### 3. Genre Trends Over Time

Analyzes the number of songs belonging to different genres across time.

This provides insights into how the presence and distribution of music genres have changed over different periods.

### 4. Artist Popularity and Similarity

Analyzes an artist's popularity over time and compares it with similar artists.

Artist similarity is determined using the available music characteristics and patterns in the dataset.

### 5. Customized Playlist Generator

Generates a personalized playlist based on user-selected music features.

Users can define their preferred characteristics and discover songs that match their selected criteria.

## Machine Learning

The project applies machine learning techniques for predictive, clustering, and recommendation tasks, including:

* Popularity Prediction
* Clustering
* Genre Classification
* Artist Similarity
* Playlist Generation

The models use music and audio features extracted from the dataset to identify patterns and generate predictions and recommendations.

## Data Analysis

The analysis covers:

* Music feature distributions
* Song popularity patterns
* Genre distribution
* Genre evolution over time
* Artist popularity trends
* Similarity between artists
* Relationships between music features and popularity

## Deployment

The complete project was deployed as an interactive **Streamlit web application**, allowing users to interact with the trained models and explore music insights through a user-friendly interface.

## Project Outcome

The project combines **data analysis, machine learning, clustering, similarity analysis, and recommendation techniques** into a single interactive music platform.

The platform enables users to interact with music data through **prediction, genre exploration, trend analysis, artist comparison, and personalized playlist generation**.
